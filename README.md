# 🎮 2D横向卷轴冒险游戏

![Unity](https://img.shields.io/badge/Unity-6000.4.5f1-000000?logo=unity)
![C#](https://img.shields.io/badge/C%23-12.0-239120?logo=csharp)
![License](https://img.shields.io/badge/license-MIT-green)

基于 **Unity 6.4 (6000.4.5f1)** 开发的 2D 横向卷轴冒险游戏，包含移动、二段跳、攻击、防御、技能、敌人AI、陷阱机关、收集物和生命值等完整游戏系统。

> ⚠️ 本项目使用正版 Unity 6 引擎开发，**不是**国内的"团结引擎"

---

## 🎯 游戏流程

1. **主菜单** → 点击"开始游戏"
2. **关卡 1** → 收集果子，避开陷阱，到达终点旗帜
3. **关卡 2** → 继续冒险，到达终点旗帜
4. **胜利场景** → 通关成功
5. **失败场景** → 生命耗尽后进入失败画面（可返回主菜单）

---

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| A / ← | 向左移动 |
| D / → | 向右移动 |
| 空格 | 跳跃（空中可二段跳） |
| J | 近战攻击 |
| K | 防御（抵挡正面伤害） |
| L | 释放技能（发射火球） |

| 脚本 | 功能 |

| `Enemy.cs` | 敌人巡逻AI、碰撞判定（踩踏消灭/正面受伤） |

## 🧩 技术亮点

- **新输入系统** — 支持键盘 A/D 和方向键
- **单例模式** — `GameManager` 全局唯一实例，`DontDestroyOnLoad` 跨场景持久化
- **二段跳** — `jumpCount` 计数 + `BoxCast` 地面检测
- **状态互斥** — 攻击/防御/技能/受伤状态互斥，防止动作冲突
- **双计时器系统** — 每个技能独立维护持续时间和冷却时间
- **敌人AI** — 两点巡逻、等待折返、踩踏判定
- **BoxCast 地面检测** — 精确的碰撞箱地面判定
- **HashSet 去重** — 跨关卡收集物去重

## 🚀 快速开始

1. 使用 **Unity 6000.4.5f1** 打开项目
2. 打开 `star.unity` 场景作为起始场景
3. 确保所有场景已添加到 **Build Settings**
4. 点击播放按钮运行游戏
