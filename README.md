# 2D横板冒险游戏

## 引擎版本
- **Unity 6.4 (6000.4.5f1)**
- ⚠️ 重要：本项目使用正版Unity 6引擎开发，**不是**国内的"团结引擎"

## 游戏流程说明
1. 开始游戏 - 点击主菜单的"开始游戏"按钮进入第一关
2. 关卡1 - 玩家控制角色，收集果子，避开陷阱
3. 关卡2 - 到达关卡2的终点旗帜
4. 胜利场景 - 通关后进入胜利画面
5. 失败场景 - 生命耗尽后进入失败画面，可以返回主菜单

## 脚本说明

### 玩家控制
| 脚本名 | 功能 | 挂载对象 |
|--------|------|----------|
| `player.cs` | 玩家移动、跳跃、动画状态管理 | 玩家角色 |
| `PlayerDeath.cs` | 玩家死亡逻辑、播放死亡动画 | 玩家角色 |

### 摄像机
| 脚本名 | 功能 | 挂载对象 |
|--------|------|----------|
| `CameraFollow.cs` | 摄像机跟随玩家移动 | 主摄像机 |

### 收集物
| 脚本名 | 功能 | 挂载对象 |
|--------|------|----------|
| `Collectible.cs` | 收集果子、播放音效、增加分数 | 奖励物品（果子） |

### 关卡与胜利
| 脚本名 | 功能 | 挂载对象 |
|--------|------|----------|
| `flag.cs` | 关卡终点旗帜，检测玩家到达并跳转场景 | 关卡终点旗帜 |
| `GameManager.cs` | 管理游戏全局数据（生命、分数、已收集果子记录） | GameManager空对象 |
| `LivesDisplay.cs` | 显示生命和分数UI | UI Canvas |

### 陷阱与障碍物
| 脚本名 | 功能 | 挂载对象 |
|--------|------|----------|
| `trap1.cs` | 地刺陷阱，检测玩家碰撞并触发死亡 | 地刺/陷阱 |
| `move island.cs` | 移动平台，让玩家跟随平台一起移动 | 移动平台 |
| `rotate.cs` | 物体旋转动画 | 旋转障碍物 |
| `trap move.cs` | 陷阱在两点之间来回移动 | 移动陷阱 |

### UI与菜单
| 脚本名 | 功能 | 挂载对象 |
|--------|------|----------|
| `start.cs` | 开始游戏按钮，重置游戏数据并进入第一关 | 主菜单开始按钮 |
| `end.cs` | 退出游戏按钮 | 退出按钮 |
| `again.cs` | 重新开始按钮，返回主菜单 | 失败场景重新开始按钮 |

## 注意事项
1. 确保所有场景都添加到Build Settings中
2. 玩家标签必须设置为"Player"
3. 检查Tilemap Collider的阻尼和挤压值，避免角色卡顿
4. 移动平台需要添加Rigidbody 2D组件并设为Kinematic
5. 各脚本的公共字段请在Unity Inspector中正确配置
